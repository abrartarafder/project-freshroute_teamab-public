1. OVERVIEW
---------------------------------------------------
- Express + Mongoose API powering organic, ethically raised, recipes, and orders data.
- Connects to MongoDB using a connection string in .env (MONGO_URI); PORT defaults to 4000.
- Legacy JSON files remain for reference or manual seeding.

2. REQUIREMENTS / PREREQUISITES
----------------------------------------------------
-Node.js: 20.19+ (recommended)
-npm: 10+
-OS: Windows / macOS supported
-Recommended tools: VS Code, Git, MongoDB Compass
-Env vars: MONGO_URI (required), PORT (optional, default 4000)

3. HOW TO CONNECT TO THE DATABASE
----------------------------------------------------
- Add MONGO_URI=<your connection string> to backend/.env
- Install + run: cd backend && npm install && npm run dev (listens on port 4000)
- Compass example connection string: mongodb+srv://freshrouteDB:eecs3311W26@freshroute-cluster.ivpzykz.mongodb.net/freshroute?retryWrites=true&w=majority&appName=freshroute-cluster

6. KEY COMPONENTS
----------------------------------------------------
- db.js: connectDB wraps mongoose.connect and fails fast if MONGO_URI is missing.
- Organic/EthicallyRaised/Recipe models: price, unit, currency, category, inventory, imageUrl.
- Order model: orderId, address, delivery slot/date, totals, line items; unique orderId enforced.
- Controllers: category controllers fetch sorted collections; OrderController handles list/create/delete with conflict handling.
- app.js: mounts /api/organic, /api/ethically-raised, /api/recipes, /api/orders plus /health.

7. API Routes
----------------------------------------------------
- Health check: GET /health
- Organic catalogue: GET /api/organic
- Ethically raised catalogue: GET /api/ethically-raised
- Recipes catalogue: GET /api/recipes
- Orders: GET /api/orders, POST /api/orders, DELETE /api/orders/:id
- Legacy JSON (optional): /api/catalog/organic, /api/catalog/ethically-raised, /api/catalog/recipes

8. STATE & DATA FLOW
----------------------------------------------------
- Requests flow: Express route -> controller -> Mongoose model -> MongoDB collection.
- Orders POST validates the presence of orderId and enforces uniqueness; failures return 400/409.
- JSON data files are not auto-seeded; use POST /api/orders or import scripts for seeding.
- Logging: server logs MONGO_URI presence and prints startup URL.
