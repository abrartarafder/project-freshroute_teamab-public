1. OVERVIEW
---------------------------------------------------
- React 19 + Vite frontend for Organic/Ethically Raised catalogs, Recipes, and a client-side cart.
- Styling: Bootstrap 5 + custom CSS; icons via react-icons.

New in Sprint 3
---------------------------------------------------
- Added Orders page with year filters and deletion, backed by the Orders API.
- Cart checkout now collects address, delivery slot/date, card stub, and creates Orders via API + localStorage fallback.
- Recipe “Add to cart” also adds scaled grocery items grouped under recipe-grocery.

2. REQUIREMENTS / PREREQUISITES
----------------------------------------------------
-Node.js: 20.19+ (recommended)
-npm: 10+
-OS: Windows / macOS supported
-Recommended tools: VS code, Git, MongoDB Compass (optional, for viewing DB)
-Env: set VITE_API_BASE_URL to point at backend (defaults to http://localhost:4000).

3. HOW TO RUN
----------------------------------------------------
- cd frontend && npm install
- Dev server: npm run dev (http://localhost:5173/)
- Build: npm run build (outputs to dist/)
- Preview build: npm run preview
- Lint: npm run lint

----------------------------------------------------

5. ROUTING (CLIENT-SIDE)
----------------------------------------------------
- /                   -> Landing page
- /organic            -> Organic category
- /ethically-raised   -> Ethically raised category
- /recipes            -> Recipes page
- /cart               -> Cart page
- /orders             -> Order history
- Unknown paths fall back to Landing

6. KEY COMPONENTS
----------------------------------------------------
- navbar.jsx: responsive nav with search and cart count badge.
- Landing.jsx: hero, links to organic page, benefits list with imagery.
- Recipes.jsx: recipe cards with “add recipe” and grocery auto-add.
- Organic/EthicallyRaised: catalog grids sourced from API.
- Cart.jsx: checkout form (address, date/slot, payment stub) + order submission.
- Orders.jsx: reads orders from API (fallback to localStorage), filters by year, delete action.

7. STYLING
----------------------------------------------------
- Bootstrap grid for layout; custom CSS in page/component files.
- Colour accents: variations of green, black, white, gold/green highlights; assets in src/assets/landing/.

8. STATE & DATA FLOW
----------------------------------------------------
- cartStore.js keeps cart data in localStorage and exposes useCart to share count/subtotal.
- API base URL from VITE_API_BASE_URL, fetches products, recipes, and orders from backend.
- Adding a recipe creates both a recipe line item and generated grocery items grouped under recipe-grocery.
- Cart checkout posts to /api/orders and also saves to localStorage (fr-orders) as offline fallback.
- Orders page fetches /api/orders, with localStorage fallback, and supports delete via DELETE /api/orders/:id.

9. EXTERNAL LIBRARIES
----------------------------------------------------
- react, react-dom, vite, bootstrap, react-bootstrap, react-icons.
- ESLint + React plugins for linting.
