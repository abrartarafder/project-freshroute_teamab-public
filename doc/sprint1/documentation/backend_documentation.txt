6. KEY COMPONENTS
----------------------------------------------------
- db.js: this file handles the connection between the backend application and the MongoDB database.
- ProductController.js: this file contains controller functions that handle product-related API requests. The createProduct    function creates a new product in the database using the data provided in the request body and returns the created product.
- Product.js: this file defines the Product model using a schema that specifies the structure of product documents in the      database, including fields such as name, price, category, and inventory.
- productRoutes.js: this file defines the API routes for product-related requests using Express Router.

7. API Routes
----------------------------------------------------
- Get All product: GET /api/products
- Add a Product: POST /api/products
