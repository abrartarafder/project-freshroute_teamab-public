1. OVERVIEW
----------------------------------------------------
- React 19 + Vite frontend for browsing categories, recipes, and cart flows.
- Styling: Bootstrap 5 + custom CSS; icons via react-icons.

2. HOW TO RUN
----------------------------------------------------
- cd frontend && npm install
- Dev server: npm run dev (http://localhost:5173/)
- Build: npm run build (outputs to dist/)
- Preview build: npm run preview
- Lint: npm run lint

3. FOLDER STRUCTURE
----------------------------------------------------
frontend/
 ├── src/
 │    ├── App.jsx (pathname-based router)
 │    ├── main.jsx (entry point)
 │    ├── index.css (global styles)
 │    ├── assets/ (logos, hero images)
 │    ├── components/
 │    │    └── navbar.jsx (react-bootstrap nav)
 │    └── pages/
 │         ├── Landing.jsx + Landing.css (hero + value props)
 │         ├── Organic.jsx (category stub)
 │         ├── EthicallyRaised.jsx (category stub)
 │         ├── Recipes.jsx + Recipes.css (recipes UI)
 │         └── Cart.jsx (cart stub)
 ├── public/
 ├── index.html
 └── vite.config.js

4. ROUTING (CLIENT-SIDE)
----------------------------------------------------
- /                   → Landing page
- /organic            → Organic category
- /ethically-raised   → Ethically raised category
- /recipes            → Recipes page
- /cart               → Cart page
- Unknown paths fall back to Landing

5. KEY COMPONENTS
----------------------------------------------------
- navbar.jsx: responsive nav with search, cart badge; props userName, activeKey, onSearch, cartCount.
- Landing.jsx: hero, CTA to /organic, benefits list with imagery.
- Recipes.jsx: styled layout ready for recipe cards (static this sprint).
- Organic/EthicallyRaised/Cart: skeleton pages reusing navbar/footer.

6. STYLING
----------------------------------------------------
- Bootstrap grid for layout; custom CSS in page/component files.
- Color accents: navy base, gold/green highlights; assets in src/assets/landing/.

7. STATE & DATA FLOW
----------------------------------------------------
- No global state manager yet; props pass cart count/username placeholders.
- Search box calls onSearch (console.log in Landing).
- API wiring planned for Sprint 2 (products, recipes, cart).

8. EXTERNAL LIBRARIES
----------------------------------------------------
- react, react-dom, vite, bootstrap, react-bootstrap, react-icons.
- ESLint + React plugins for linting.
