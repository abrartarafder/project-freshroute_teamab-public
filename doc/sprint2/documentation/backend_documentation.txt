1. OVERVIEW
---------------------------------------------------
- Express + Mongoose API for product data.
- Connects to MongoDB using a connection string in .env (MONGO_URI).
- Legacy JSON files remain for reference or manual seeding.

2. REQUIREMENTS / PREREQUISITES
----------------------------------------------------
-Node.js: 20.19+ (recommended)
-npm: 10+
-OS: Windows / macOS supported
-Recommended tools: VS Code, Git, MongoDB Compass

3. HOW TO CONNECT TO THE DATABASE
----------------------------------------------------
- Add MONGO_URI=<your connection string> to backend/.env
- Install + run: cd backend && npm install && npm run dev (listens on port 4000)
- Compass example connection string: mongodb+srv://freshrouteDB:eecs3311W26@freshroute-cluster.ivpzykz.mongodb.net/freshroute?retryWrites=true&w=majority&appName=freshroute-cluster

6. KEY COMPONENTS
----------------------------------------------------
- db.js: connectDB wraps mongoose.connect and fails fast if MONGO_URI is missing.
- ProductController.js: createProduct (POST) and getProducts (GET) handlers.
- Product.js: Mongoose schema for name, price, category, inStock with timestamps.
- productRoutes.js: Express Router wiring for /api/products (GET, POST).

7. API Routes
----------------------------------------------------
- Health check: GET /health
- Get all products: GET /api/products
- Add a Product: POST /api/products

8. STATE & DATA FLOW
----------------------------------------------------
- Requests flow: Express route -> controller -> Mongoose model -> MongoDB collection.
- JSON data files are not auto-seeded; use POST /api/products or an external script if needed.

9. EXTERNAL LIBRARIES
----------------------------------------------------
- mongoose
- express 
- cors 
- dotenv
